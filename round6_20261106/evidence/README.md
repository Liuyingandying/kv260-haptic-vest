当前发布运行基线是 M2 + f30、DGM2 外部监督联调模式，CH1/CH3 的8片PCA、128个逻辑位置、强度上限1。其余128路没有被本KV260版本验收；未逐点校准128个实际物理位置。**C3没有加载，不能用C3候选源码解释M2运行行为。**

停止后8片PCA共512个PWM寄存器字节精确为FULL_OFF；这证明寄存器状态，不证明独立动力关断。SDK stop返回、应用析构完成与设备恢复是三个不同事实，资源恢复保持 `UNKNOWN`。正式捕获帧龄、时钟映射仍 `BLOCKED`，`FRESH=0`，不宣称生产安全模式通过。

已知M2每帧BEGIN会短暂撤销控制；续窗也包含明确关闭、排空、重新使能间隙。因此这里的持续采集/运行不表示无间断PWM。短OFF结论绑定冻结M2源码包成员及SHA，未引用后续C3当前文件。

本目录不含原始相机帧、长串口/SDK日志、设备序列号、个人登录信息或本机绝对路径；不提供自动启动真实执行器的快捷操作。
