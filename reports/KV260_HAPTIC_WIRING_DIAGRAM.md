# KV260 触觉控制 接线示意图

**图例**：`[C]` = CONFIRMED（官方/双源确认） · `[I]` = INFERRED（RTL 或设计推断）
`[?]` = UNKNOWN（禁止连接） · `[X]` = BLOCKED（未确认前禁止接线）

> 本文件中的虚线框与 `[?]` 项**表示尚未确认的连接**，不得据此焊接或接线。

## 图 3：单片 PCA9685 与振动驱动级连接

```
                     +3.3V (逻辑域)
                       │
                   ┌───┴───┐  VDD
                   │       │
   I²C SCL ─────────┤ SCL   │
   I²C SDA ─────────┤ SDA   │         PCA9685
                   │       │
   FPGP oe_n ───────┤ OE#   │  ← 低有效；外部 3.3V 上拉保证未配置时=关断 [I]
                   │       │
                   │  PWMx ├──────┐
                   └───────┘      │
                                  │   ┌──────────────┐
                     +V (执行器域) │   │  驱动级       │      ┌────────┐
                       │          └──▶│ (型号未知)   ├─────▶│ 振动   │
                   ┌───┴───┐          └──────────────┘      │ 执行器 │
                   │  V+   │  ← 必须独立供电，[X] 额定未知   └────────┘
                   └───────┘
   ─────────────────────────────────────────────────────────────  GND 必须共地 [?]
```

**关键约束**
- **VDD（3.3 V 逻辑）与 V+（执行器）是两个独立电源域，禁止并接。**
- OE# 需外部 3.3 V 上拉：FPGA 未配置时引脚高阻 → 靠上拉拉高 → PCA9685 输出关闭。
- PWM 频率：`PRE_SCALE=0x79` → 25 MHz/((121+1)·4096) = **50.03 Hz**（仿真已证）。
- 驱动级与执行器的额定电压/电流/极性全部 **UNKNOWN**，禁止试供电。
